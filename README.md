# Мика

Голосовой собеседник с аниме-аватаром и кружочки для астро-бота.

| Что | Где |
|---|---|
| Сервер голосового чата | `server.py`, характер в `persona.txt` |
| Голос: синтез, проверки, губы | `mika_voice.py` |
| Страница аватара | `static/index.html`, библиотеки в `static/vendor/` |
| Рендер кружочков и сервис для очереди | `video/` |
| Дообучение голоса | `dataset/` |
| Запекание анимаций в Unity | `unity-bake/` |

## Чего здесь нет

Эти файлы не хранятся в гите, их нужно положить рядом вручную:

- `models/` — веса голоса (`masha-calm-tts`) и прочие модели;
- `static/models/*.vrm`, `static/motions/*/`, `assets/` — аватары и движения;
- `voices/` — образцы голоса: `.wav` и рядом `.txt` с его текстом;
- `data/`, `dataset/wavs/`, `dataset/texts.txt` — датасеты, фразы создаёт `dataset/gen_texts.py`.

Аватары и движения нельзя выкладывать по условиям авторов: Kuroto (VN3, без 18+ и
без передачи модели), пак Sway (без передачи), для клипов VRoid нужна атрибуция.
При передаче голоса Маши прикладывается `data/dialogs/LICENSE.md`.

## Запуск

`server.py` и `dataset/gen_texts.py` требуют переменную окружения `LLM_URL`: адрес
`/v1/chat/completions` у llama. Значения по умолчанию нет, без неё они не запустятся.

## Кружочки

Сервис `mika-notes` работает на машине генерации и вызывается только через очередь
`ai-api-stuff` (`POST /api/video-note`): очередь освобождает видеокарту перед
рендером. Напрямую в прод-сервис ходить нельзя.

Код подключён в контейнер томом из `/home/user/apps/mika`. Новая версия файла
подхватывается при следующем запуске процесса рендера, а смена зависимостей
требует пересборки образа: `video/Dockerfile`, `video/docker-compose.yml`.

Локальный запуск рендера:

```
python video/note.py "Сценарий с метками [greet] жестов" out.mp4
```

Ограничения Telegram для кружка: 640×640, не дольше 60 секунд и не больше 12 МБ.
